         FAQ
        
Questions, answered

      


      

        

          Does Lumora work with any framework?
          
Yes. Lumora is pure CSS custom properties plus a ~1 KB runtime. It works with React, Vue, Svelte, Angular, Astro or plain HTML — anything that can set an attribute on the root element.

        

        

          How do you avoid the flash of the wrong theme?
          
A tiny blocking script reads the saved preference (or the OS setting) and writes data-theme onto the <html> element before the first paint. No flicker, ever.

        

        

          Is dark mode accessible?
          
Every foreground/background pair in both themes is verified at WCAG AA or better, including muted text, borders and focus indicators.

        

        

          Can I use my own brand colours?
          
Absolutely. The entire system is driven by CSS variables — override six tokens and the whole component library re-skins itself, in both light and dark. Try the live customizer (bottom-left) to see it in action.

        

        

          What happens if a user changes their OS theme?
          
If the user hasn't explicitly picked a theme, Lumora follows the operating system live and updates instantly when it changes.

        

        

          Is there an offline mode or app install?
          
Yes. Lumora ships with a service worker and web app manifest, so it can be installed to your home screen or dock and continues to load instantly when offline.
